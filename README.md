## Requirements

Di project ini, kami diharuskan untuk menggunakan Python versi 3.9.x agar kompatibel pada versi PyQt yang digunakan, yaitu PyQt6. Berikut detailnya:

3. **PyQt6:** 610.2
1. **Python**  3.9.13
2. **pip**  22.0.4

Selain 3 point di atas, pastikan komputer kalian sudah terinstall [Git](https://git-scm.com/).

## Instalasi

Untuk memulai project ini, bisa ikuti langkah - langkah di bawah:

1. Buka terminal atau CMD
2. Clone project: `git clone https://github.com/evanalifian/pyqt6-calculator.git`
3. Membuat virtual environment: `python -m venv env`
4. Menjalankan venv: `.\env\Scripts\activate`
5. Install packages: `pip install -r requirements.txt`
